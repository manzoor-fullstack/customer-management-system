# Customer Management System

## Tech Stack

### Frontend
- React.js
- Tailwind CSS
- Axios
- React Router DOM

### Backend
- Node.js
- Express.js
- MongoDB
- JWT Authentication

## Features

- User Authentication
- Customer CRUD
- Search Customers
- Responsive Dashboard
- Protected Routes

## Installation

### Backend

cd Backend
npm install
npm run dev

### Frontend

cd cms-frontend
npm install
npm run dev
